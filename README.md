# Jon Tepper

Data scientist, Derby, UK. I build forecasting and classification systems that have to make decisions with real money or real policy behind them, and I care about whether the probabilities they produce can be trusted.

I run [Perceptronix Ltd](https://www.perceptronix.net/), a small applied machine learning consultancy. Since 2018 the work has been production prediction systems for investment and trading clients (LightGBM and neural network ensembles, calibrated against a market price, with the validation and drift monitoring to keep them honest), and UK inflation forecasting with the University of Birmingham and NIESR using multi-recurrent neural networks, which I presented at NIESR in London in September 2026.

Before that I spent eighteen years at Nottingham Trent University, finishing as Principal Lecturer in Computer Science and School Quality Manager. My PhD was on modular recurrent networks for language processing, which is still the thread running through most of what I do.

## What you will find here

Most of my client work lives in private repositories. The public ones are just fun projects I am working on when I have time:

- **DecisionReadyClassifier**: a credit-risk classifier evaluated under asymmetric decision costs, with calibration treated as a first-class result. Later stages add retrieval and constrained LLM explanations; the classifier stays the decision maker.

Everything is Python, with a Makefile, a config file and a `results/` folder per run. I like pipelines that can be re-run and audited six months later.

## Tools I actually use

Python (pandas, scikit-learn, LightGBM, PyTorch, statsmodels), SQL, SHAP, MLflow, Docker, AWS. Recurrent networks for time series, gradient boosting for tabular problems, and a fair amount of econometrics (SVAR, SARIMAX, regime switching) when the question calls for it.
